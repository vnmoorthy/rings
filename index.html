How to read it

  • Disclosure is not usage. Rings only sees what commits say. Many people use AI without a trailer, and a trailer can be added or removed by settings. A ring with no colour means no signal, never "written by a human".
  • AI co-author / assisted-by trailer: a Co-authored-by line naming a coding agent by its own display name or no-reply address (for example Claude <noreply@anthropic.com>), or an Assisted-by, AI-assisted or Generated with … line naming a tool. Lines that GitHub squash merges push out of the trailer block are read too. Company email domains and people's full names (Claude Paroz, Devin Weaver) are not counted.
  • AI agent account: the commit author is an agent's own account, such as copilot-swe-agent[bot], devin-ai-integration[bot] or google-labs-jules[bot].
  • Bot-named account: an author whose name or address marks it as automation ([bot], *-bot, … Bot, github-actions, robobun@oven.sh ...), plus routine chores (generated files, lockfiles, formatting) pushed by an agent's account. Rings does not know what runs behind such an account.
  • Non-merge commits reachable from the default branch, grouped by author date in UTC. Ring width is the square root of the month's commits, capped at 2.5 times the median so one burst cannot flatten the rest.
  • Maintainers: if you would like your repo removed or a bot list corrected, open an issue and it will be done.
